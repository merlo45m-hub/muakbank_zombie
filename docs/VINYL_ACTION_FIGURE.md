# Phase 2 — Refined Vinyl Action-Figure Aesthetic (Issue #21)

Follows Phase 1 (`1698ee8`, Lighting & Atmosphere / environment setup).
Goal: glossy moulded-vinyl look for the low-poly characters, with a crisp
silhouette highlight and fog that separates depth without dissolving facets.

## Hard constraint (DESIGN.md §6)
Mobile renderer, <=3 real-time lights, <=1 shadow caster, 60 FPS on S26 Ultra,
no lightmaps. Phase 1 deliberately left `volumetric_fog_enabled = false` because
Godot's volumetric pass is expensive on mobile. **Phase 2 does not undo that**:
volumetric fog ships as a HIGH-tier opt-in; MOBILE (the default, i.e. all phones)
is byte-for-byte the Phase 1 environment behaviour.

## 1. Sharp dynamic rim lighting — zero new lights

Two mechanisms, neither adding a real-time light:

**a) Fresnel overlay shader** — `shaders/vinyl_rim.gdshader`, materialized as
`resources/materials/vinyl_rim.tres` (generated by `ResourceSaver`, not hand-authored).
`render_mode unshaded, blend_add` so it is attached as `material_overlay` on a
`MeshInstance3D`: it ADDS a rim to the existing surface and never replaces the
character's authored albedo. "Dynamic" = Fresnel is computed from `NORMAL . VIEW`,
so the highlight tracks the camera as it orbits the figure.

| Uniform | Value | Why |
|---|---|---|
| `rim_color` | `(0.55, 0.72, 1.0)` | cool moon-side edge, matches the blood-moon night |
| `rim_power` | `4.0` | narrows the Fresnel falloff → sharp edge, not a broad halo |
| `rim_strength` | `1.15` | crisp but not blown out |
| `rim_threshold` | `0.45` | `smoothstep` hard-threshold so low-poly facet edges pop |
| `sheen` | `0.28` | soft vinyl bloom under the sharp rim |

**b) Existing `PlayerRim` omni tuned** (still inside the 3-light budget: 1
directional + 2 street lamps + PlayerFill + PlayerRim are all pre-existing):
`light_energy 0.95 → 1.25`, `omni_range 5.0 → 3.2` (tighter = crisper),
`light_color (0.62,0.72,1) → (0.52,0.70,1)` (cooler). No new nodes.

Wired in `scenes/main/game.tscn`: `material_overlay` on `Player/PlayerVisuals/Body`
and `Head`, plus a `VinylLook` node (`VinylLookController.gd`, `tier=0` MOBILE).

## 2. Volumetric fog calibration (HIGH tier only)

`scripts/world/VinylLookController.gd` — `QualityTier { MOBILE=0, HIGH=1 }`.
`apply_tier(HIGH)` sets the calibrated volumetric pass; `apply_tier(MOBILE)`
restores `volumetric_fog_enabled = false`. Round-trip is idempotent.

| Property | Value | Why it complements low-poly |
|---|---|---|
| `volumetric_fog_density` | `0.021` | barely above Phase 1's 0.02 haze; facets stay readable |
| `volumetric_fog_length` | `42.0` m | short range = ground mist + depth, not a uniform wash |
| `volumetric_fog_anisotropy` | `0.35` | mild forward-scatter toward the moon |
| `volumetric_fog_detail_spread` | `1.6` | coarse froxels = cheaper on a mobile GPU |
| `volumetric_fog_ambient_inject` | `0.22` | keeps unlit facets from crushing to black |
| `volumetric_fog_albedo` | `(0.30,0.22,0.24)` | blood-moon grey/rose |
| `volumetric_fog_emission` | `(0.16,0.09,0.10)` @ `0.12` | faint warm glow, no light needed |
| `temporal_reprojection` | `true` @ `0.85` | suppresses froxel noise on flat facets |

### Ownership split — IMPORTANT
`scripts/gameplay/WeatherSystem.gd` **owns flat `fog_density` at runtime** and
overrides the resource value per weather state: `CLEAR 0.0015`, `FOG 0.012`,
`RAIN/STORM 0.004` (its own comment: 0.02–0.05 was a near-opaque wall). This is
pre-existing, intentional behaviour, NOT a Phase 1 bug. WeatherSystem does NOT
touch height-fog or any `volumetric_fog_*` property, so:
- Phase 1's ground mist (`fog_height`, `fog_height_density`, scatter, aerial
  perspective) survives untouched.
- Phase 2's HIGH-tier volumetric settings are owned solely by VinylLookController.
- No writer conflict. Verified at runtime: `MOBILE_VOLUMETRIC_OFF=true` with
  `fog_density=0.0015` (CLEAR weather, as expected).

## 3. Verification (live, xvfb headless Godot 4.7, 2026-11-15)
- Shader compiles on `--headless --import` (0 shader/parse errors); loads as a
  `ShaderMaterial` with `rim_power=4.0`.
- Tier probe: MOBILE off / HIGH on with all 10 calibrated values / round-trip
  back off → `VINYL_PHASE2_PASS=true`.
- **Boot probe of the real `game.tscn`**: `PLAYER_RIM energy=1.25 range=3.2`,
  `BODY_OVERLAY`/`HEAD_OVERLAY` both ShaderMaterial pointing at
  `res://shaders/vinyl_rim.gdshader`, `CONTROLLER_PRESENT=true tier=0`,
  `MOBILE_VOLUMETRIC_OFF=true`, HIGH flip activates `v_density=0.021
  v_length=42`, `VINYL_WIRING_PASS=true`.
- Full gates: static `ISSUES: 0`, import 0 parse errors, REGRESSION PASS 5/5,
  GDUnit 12/12, `FULL_PROGRESSION_PASS=true`.
- Two bugs found and fixed: (1) the `VinylLook` node was initially inserted
  between `AchievementManager`'s declaration and its `script =` line, stealing
  that script and leaving AchievementManager scriptless; (2) the probe asserted
  MOBILE after flipping to HIGH.
