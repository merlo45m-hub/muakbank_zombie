     pounce instead of punching. Root cause located: scripts/core/ProceduralAnimator.gd
     lines ~361-364 auto-call trigger_attack() on the is_attacking rising edge, which
     runs the whole-body lunge curve (pos.z lunge + rot.x pitch-down). A human punch
     should move the ARM/WEAPON, not pitch the torso.

     Suspects: rect overlap (JUMP/ATTACK/SWAP cluster), or signal routing.

     colliders, geometry). Cause not yet proven.
