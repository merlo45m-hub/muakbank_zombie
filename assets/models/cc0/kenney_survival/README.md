# Kenney Survival Props (CC0)

- Source: Kenney CC0 asset pack (survival models, kenney.nl)
- Pack: `kenney_survival`
- License: CC0 1.0 Universal (see `LICENSE.txt`)
- Intended use: scavenged survival props for Muakbank Zombie
- Files: 80 x `.glb` (1,298,392 bytes total)
- Destination: `assets/models/cc0/kenney_survival/`

Includes barrels, bedrolls, chests, fences, bottles, boxes, buckets,
campfires and fish for dressing survival scenes.

`Godot import sidecars (*.glb.import) are generated by the engine on first
headless import and are regenerated by `tools/regression_smoke.sh`; they are
not committed here because Godot/xvfb is not installed on this VPS (see
asset_import_report.txt).
