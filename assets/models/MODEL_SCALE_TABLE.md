## How to use

1. Find your model's category in the summary table below.
2. Apply the **recommended Godot scale** to the `scale` property on your `MeshInstance3D` or `PackedScene` instance.
3. The scale factor converts Kenney's normalized 2×2×2 unit grid into believable real-world metres.
4. For per-model precision, look up the exact bbox in the detailed table at the bottom.

**World scale reference:** `Player.CHARACTER_HEIGHT = 1.8m`. Level-1 buildings sit at y≈5 with ~10m tall BoxMesh placeholders.

**Key:** Kenney CC0 kits are authored on a **2×2×2 unit normalized grid**. A model with bbox `[2.0, 2.3, 2.0]` is 2 units wide/deep and 2.3 units tall in Kenney's scene. To make it ~11.5m tall in-game, scale by **5.0**.

## Methodology

- **Script:** `tools/measure_models.py` (pure Python stdlib: `struct` + `json`)
- **What it measures:** Union bounding box of all VEC3 accessors that carry `min`/`max` in the GLB JSON chunk.
- **Why union:** Multi-part models (e.g., a car with separate wheel meshes) report the bbox of ALL meshes combined, not any single mesh.
- **Scale formula:** `scale = target_real_height / bbox_height`
- **Verification:** All 288 models parsed successfully. 0 errors. Known values match (e.g., `building-a` = [2.0, 2.29, 2.0] ✓, `building-skyscraper-a` = [2.0, 3.88, 2.0] ✓, `tree-large` = [2.0, 1.77, 2.0] ✓).
