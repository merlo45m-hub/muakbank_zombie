SESSION HISTORY — hard-won lessons (use these to find GAPS)
=====================================================================
These are real events from recent sessions. If a lesson is NOT captured in a
skill or memory, that is a GAP worth reporting.

- A probe that HARD-CODED a copy of a constant and rebuilt synthetic objects
  printed "RESULT PASS" while testing nothing. Editing the real code changed
  none of its numbers. Lesson: a probe must load the REAL script/scene; run a
  NEGATIVE CONTROL (re-introduce the bug, confirm the probe FAILS).
- Godot control geometry: a full-screen Control with default mouse_filter STOP
  swallows every touch, silently disabling a feature whose handler is correct.
- Two input paths must stay in sync (keyboard ran _try_prop_interaction(), the
  mobile button did not) — a feature worked on keyboard, not touch.
- A timer that wins the game without consulting the win condition.
- A CanvasLayer root with no visible=false rendered idle defaults forever.
- _skeletal was null at attack time because rig re-instantiation + animator
  re-parent broke the handle; the is_instance_valid() guard swallowed it.
- Godot 4.7 will NOT read a custom key from project.godot (4 probes proved it);
  set_initial_value() actively clobbers file overrides.
- tar syncs that drop .godot/ wipe global_script_class_cache.cfg, so every
  class_name fails to resolve — a sync artifact, not a code bug.
- Godot 4 API renames that are PARSE-FATAL so a probe exits 124 with zero
  output and looks like a hang: get_viewport_rect() on a bare Node, and
  Rect2.intersect() (Godot 3) vs intersection() (Godot 4).
- An agent's "RESULT: VERIFIED" report where the install timestamp was stale —
  it tested an old build and produced a confident, fictional report.
- The godot-ai addon was installed but never listed in [editor_plugins]
  enabled, so the in-editor half of the bridge never loaded while
  `hermes mcp test` happily reported 47 tools.
- godot-ai MCP's live-runtime ops do not work headless on Godot 4.7; its
  EDITOR tools do.
- An agy "review" run can exit 0 having done nothing; and a build delegation can
  exit 0 having edited ZERO files. git status is the ground truth, not exit code.
- Probes must be dispatched to agents, not hand-cranked by Hermes (repeated
  user correction).
